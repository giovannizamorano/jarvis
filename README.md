## Sobre el proyecto

[![Product Name Screen Shot][product-screenshot]](https://example.com)

La inteligencia artificial se ha convertido en un elemento clave para mejorar procesos y optimizar el rendimiento en diversas áreas. Este proyecto tiene como objetivo demostrar las capacidades de un chatbot construido con tecnología de OpenAI para asistir en tareas generales de manera eficiente.

Beneficios principales de un chatbot basado en IA:

* **Aumento de la eficiencia:** Automatización de tareas repetitivas.
* **Mejor accesibilidad:** Interacción fluida mediante lenguaje natural.
* **Optimización del tiempo:** Respuestas rápidas y precisas en contextos variados.

Este proyecto es una demostración de cómo integrar modelos avanzados de lenguaje en aplicaciones prácticas.

## Getting Started

### Prerequisitos

Se recomienda el uso de Visual Studio Code para la ejecución y edición del script:
* Visual Studio Code
  ```sh
  https://code.visualstudio.com/
  ```

### Instalación

Pasos para configurar el proyecto:

1. Obtén una API Key gratuita en [https://openai.com/](https://openai.com/).
2. Clona el repositorio:
   ```sh
   git clone https://github.com/giovannizamorano/ticket_bot.git
   ```
3. Instala los paquetes necesarios:
   ```sh
   pip install openai
   pip install streamlit
   pip install pandas
   pip install json
   pip install pathlib
   pip install tempfile
   pip install uuid
   ```
4. Ingresa tu API Key en `main.py`:
   ```py
   client = OpenAI(api_key="Tu_API_Key")
   ```
